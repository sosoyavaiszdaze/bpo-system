## P1. 計測精度=学習シグナル精度原則

### 説明 (約 280 字)
全運用判断の前提として、コンバージョン計測の正しさが最上位に置かれる。米満氏理論では、計測の精度向上は単にレポートの正確性ではなく、自動入札アルゴリズムに与える学習シグナルの精度そのものを意味する。タグ発火、拡張コンバージョン、GA4 連携、データドリブンアトリビューション、オフライン CV インポート、ファーストパーティデータ同期はすべて「シグナル品質」の文脈で評価され、これが破綻している状態では他のあらゆる施策判断が無効化される。Shopping/PMAX/App 等のチャネル固有計測 (フィード/インストール CV/Consent Mode v2) も同じ系譜で、「配信前提条件」として最優先で整備される。

### 紐づくルール ID
G01, G02, G03, G04, G05, G06, G07, G08, G09, G09b, G10, G46, G68, G68c, G71, G76, G78, G79, G81

### 業界常識との差分
- **業界常識**: 計測は「レポートが正しく出るための土台」。重複や欠損があれば直す程度。
- **米満氏理論**: 計測は「自動入札に与える学習シグナル」そのもの。1 つの欠損は学習精度の全面低下を意味し、最優先で全項目を整備する。

### 米満氏理論の根拠引用 (`redesign_note`)
- G01: 「計測の正しさは全運用判断の前提。最優先項目」
- G03: 「計測精度向上 = 学習シグナル精度向上」
- G08: 「シグナル評価の基準軸そのもの」
- G09: 「ファーストパーティデータをシグナルとして注入」
- G68: 「学習初期値の人的設計」

### google_structure_dependency: **medium**
GA4 連携、拡張 CV、データドリブンアトリビューションは Google Ads 固有の API/連携機能を伴うが、思想 (計測=シグナル) は媒体非依存。

### meta_applicability: **high**
Pixel/CAPI、Conversions API、Advantage+ Audience Signals に同思想を直接転用可能。

### tiktok_applicability: **high**
Pixel/Events API/Customer File Upload に同思想を直接転用可能。

### 関連原則
- **派生**: P3 (計測精度が前提となるため、結果指標を否定するには原因変数の正確な計測が必要)
- **派生**: P4 (ネガティブシグナル保持は計測整備が前提)
- **前提**: なし (P1 が全原則の前提)

## P2. 機械学習保護原則 (短期判断による長期破壊回避)

### 説明 (約 320 字)
自動入札 (Smart Bidding) を前提とした運用では、短期的な判断介入が学習プロセスを破壊し、長期最適化を毀損する。米満氏理論では、学習フェーズ滞留・入札戦略の頻繁な変更・ピン留め過剰・過度な自動アセット任せが「システム最適化の阻害要因」として明示的に否定される。一方で、計画的な季節調整や入札戦略の正しい初期選定は「人的介入として正当」とされ、無介入主義ではない。要点は「アルゴリズムが収束すべき期間に外乱を与えない」「学習が利用するパラメータを過度に固定しない」の 2 点。これは結果として「悪く見える数値があっても短期で止めない」という KillRule への懐疑にも繋がる (P3 と接続)。

### 紐づくルール ID
G11, G11b, G12, G14, G16, G18, G38, G57, G66

### 業界常識との差分
- **業界常識**: 数値が悪いキャンペーンは早期に停止・入札変更で対処。Smart Bidding でも頻繁な目標値見直しを行う。
- **米満氏理論**: 学習未完了状態で停止/変更すると長期最適化を毀損。介入は「計画された人的介入」のみ正当化される。

### 米満氏理論の根拠引用 (`redesign_note`)
- G12: 「学習未完了 = 短期判断を急いで長期最適化を毀損」
- G14: 「短期判断の積み重ねが長期学習を破壊」
- G38: 「システム最適化の阻害要因」(ピン留め過剰)
- G16: 「計画的な人的介入として正当」(季節性調整)
- G66: 「システム自動化に任せすぎるリスク」(動画自動生成)

### google_structure_dependency: **low**
学習フェーズ概念や Smart Bidding は Google 固有だが、思想 (短期判断による学習毀損回避) は媒体非依存。

### meta_applicability: **high**
Meta Advantage+ / CBO / 学習フェーズに同思想を直接転用可能。

### tiktok_applicability: **high**
Smart+ / Automated Creative Optimization に同思想を直接転用可能。

### 関連原則
- **対立**: P5 (Budget Lost 解消の即時介入と、学習保護のための介入抑制の間にトレードオフ)
- **派生**: P3 (短期数値で停止判断しないという立場が、結果指標非依存原則に繋がる)
- **派生**: P8 (自動化を前提とすれば手動時代の頻繁な介入手法は不要)

## P3. 結果指標非依存・原因変数置換原則

### 説明 (約 360 字)
品質スコア (Quality Score) のような「結果指標」を停止/分離判断の根拠にしない。米満氏 note によれば、品質スコアは Ad Rank の算出には使われない**結果出力**であり、原因変数 (推定 CTR / 広告関連性 / LP エクスペリエンス) の方が運用判断材料として正しい。同様に、Ad Rank Lost / IS Lost も「Budget 由来か Ad Rank 由来か」の原因分解を行わなければ意味を持たない。3x Kill Rule のような結果ベース停止ルールも、自動入札時には「止めずに編集」へと判断ロジックが置き換えられる。この原則の本質は「指標を見て動くのではなく、その指標を生む原因変数を特定して動く」という因果フローの再構築。Zynect 独自の判断ログ (P9) もこの因果分解を月次レポートに搭載する仕組み。

### 紐づくルール ID
G26, G26-NEW1, G26-NEW2, G26b, G26c, G26d, G26e

### 業界常識との差分
- **業界常識**: 品質スコアが低い KW は停止・除外。3x Kill Rule で結果が悪い広告は機械的に停止。
- **米満氏理論**: 品質スコアは結果指標であり Ad Rank に使われない (`yonemitsu_alignment: 概念的に問題`)。停止判断には使わずモニタリングのみ。原因変数 (pCTR/CPC/QS) に分解して原因を特定する。

### 米満氏理論の根拠引用 (`redesign_note`)
- G26: 「**重要**: 米満氏 note によれば品質スコアは Ad Rank 算出に使われない結果指標。停止判断の根拠にしない。モニタリングのみ」
- G26-NEW1: 「新設: G26 を結果指標から原因変数に置き換え。pCTR 低/CPC 低/品質スコア低の 3 分解」
- G26-NEW2: 「新設: 品質スコア構成要素の推定 CTR 低 KW 群から視認性課題の文字列を特定」

### google_structure_dependency: **high**
品質スコア・Ad Rank・推定 CTR・広告関連性・LP エクスペリエンスはすべて Google Ads 固有概念。判断の置き換え先 (pCTR 等) も Google 固有指標。

### meta_applicability: **medium**
Meta の Relevance Diagnostic (Quality/Engagement/Conversion Ranking) も同様に「結果ランキング指標」であり、これを停止判断に使わず原因変数 (CTR/CVR/Hook Rate 等) に分解する思想は転用可能。ただし指標体系は Google と異なる。

### tiktok_applicability: **low**
TikTok には Ad Rank / 品質スコアに対応する明示的な結果指標体系がなく、原則の構造そのものは直接転用しにくい。思想レベルでは「結果ランキング指標を停止判断に使わない」は応用可能。

### 関連原則
- **前提**: P1 (原因変数を分解するには計測精度が必要)
- **派生**: P9 (因果分解の判断ロジックは判断ログとして残す必要がある)
- **接続**: P2 (短期結果指標で停止しない立場と整合)

## P4. ネガティブシグナル保持・ポジネガ両建て原則

### 説明 (約 320 字)
自動入札の学習はポジティブシグナル (CV) だけでなくネガティブシグナル (低パフォーマンス地域、配信を止めるべき検索クエリ、低 IMP KW、低品質プレースメント、除外オーディエンス) を併せ与えることで有意差が高まる。米満氏理論の特徴的な点は、「低パフォーマンスの要素」を**削除や非表示にせず、明示的に除外シグナルとしてアカウント内に保持する**こと。低 IMP KW を「データなし」として削除するのではなく「ネガティブシグナル候補」として残す、低パフォ地域を入札ゼロでなく除外として明示する、検索語句レポートから継続的にネガティブ KW を追加する、といった運用がこの原則に基づく。

### 紐づくルール ID
G02, G07, G10, G20, G21, G27, G27b, G28, G32, G42, G54, G55, G68d, G72, G79

### 業界常識との差分
- **業界常識**: 低 IMP/低パフォーマンスの要素は「データが取れない」「ノイズになる」として削除。
- **米満氏理論**: 削除は学習に与える情報の損失。ネガティブシグナルとして明示保持し、学習有意差を高める。

### 米満氏理論の根拠引用 (`redesign_note`)
- G27: 「ネガティブシグナルの保持は学習有意差を高める」
- G32: 「削除でなく分析ノイズ低減策へ。低 IMP = ネガティブシグナル候補」(`yonemitsu_alignment: 要再定義`)
- G02: 「ポジ/ネガ両方のシグナルを学習に与える土台」
- G20: 「ネガティブシグナル (低パフォ地域) の保持」
- G54: 「ネガティブシグナル保持」(低品質プレースメント)

### google_structure_dependency: **low**
ネガティブ KW・除外プレースメント・除外オーディエンスは媒体共通機能。思想は完全に媒体非依存。

### meta_applicability: **high**
Meta の除外オーディエンス、ブロックリスト、Advantage+ Audience の除外シグナルに直接転用可能。

### tiktok_applicability: **high**
TikTok の除外オーディエンス、ネガティブターゲティングに直接転用可能。

### 関連原則
- **前提**: P1 (シグナル管理は計測整備が前提)
- **接続**: P2 (ネガティブシグナル保持は学習を強化する≒学習保護と整合)

## P5. Budget Lost 先行解消・機会損失優先原則

### 説明 (約 320 字)
パフォーマンス改善の優先順位として「効率改善 (CPA 低下) より機会損失 (IS Lost) の解消」を上位に置く。米満氏理論では、IS Lost (Budget) の解消が TO-09 の中核とされ、Budget 由来か Ad Rank 由来かを分解した上で先に Budget 制約を取り除く。ページ最上部 IS / 絶対トップ IS は単なる KPI でなく「広告クリエイティブ評価軸」として強調され、競合動向 (オークションインサイト) と並べてモニタリングする。米満氏 note06 が強調するこの「上部 IS 推移」観点は、業界で軽視されがちな指標を中核に格上げする運用設計を意味する。

### 紐づくルール ID
G13, G13b, G15, G15b, G33, G41, G44, G45, G45-NEW, G60, G75, G82-NEW

### 業界常識との差分
- **業界常識**: CPA/ROAS の効率指標を最優先に改善。IS Lost は「予算追加してから考える」程度の扱い。
- **米満氏理論**: Budget Lost を先に解消し、その上で Ad Rank Lost に取り組む。順序が固定されている。上部 IS は単なる KPI ではなく評価軸そのもの。

### 米満氏理論の根拠引用 (`redesign_note`)
- G13: 「TO-09 の中核。Budget Lost 先行解消」
- G44: 「TO-09 の中核。Budget/Ad Rank 分解の入口」
- G45: 「ページ最上部 IS。米満氏が広告クリエイティブ評価軸として強調」
- G45-NEW: 「新設: 米満氏 note06 が強調する評価軸。競合動向と並べてモニタリング」
- G41: 「深度の天井で機会損失」

### google_structure_dependency: **high**
インプレッションシェア (Search IS、絶対トップ IS、ページ最上部 IS、IS Lost Budget/Rank)、オークションインサイトはすべて Google Ads 固有の指標。

### meta_applicability: **medium**
Meta には IS に直接対応する指標がないが、Reach / Frequency / Auction Overlap / Estimated Daily Results 等で類似の「機会損失」を捉えることは可能。思想レベルでは転用可能。

### tiktok_applicability: **low**
TikTok には IS に対応する指標体系がほぼ存在しない。Spend Pacing 程度。

### 関連原則
- **対立**: P2 (機会損失解消の即時介入と、学習保護の介入抑制との間でトレードオフ)
- **派生**: P3 (Budget Lost vs Ad Rank Lost の原因分解は結果指標非依存原則と同型)

## P6. 集約優先・分離原則 (粒度過剰回避 + 評価軸異質)

### 説明 (約 360 字)
構造設計の判断軸として、「機械学習が十分なデータを蓄積できる粒度に集約」と「評価軸が異なるものは分離」の 2 つを使い分ける。SKAG (Single Keyword Ad Group) のような細粒度構造はデータ希薄化を招くため否定され、20KW 超の AG は集約 or 細分化を検討する。広告グループあたりの KW、PMAX のアセットグループ、Shopping の商品グループも同様に「集約寄り」が推奨される。一方で、ブランド KW と一般 KW、PMAX と Search のような「評価軸 (CV 質、入札論理) が異なる」ものは明確に分離する。これは細分化と分離の混同を避け、「学習が必要な単位は集約、評価が異なる単位は分離」という二軸ルール。

### 紐づくルール ID
G17, G30, G31, G39, G40, G43, G51, G53, G53b, G64, G70, G70b

### 業界常識との差分
- **業界常識**: SKAG が長らく標準。細分化することで品質スコアと CTR を最大化。
- **米満氏理論**: SKAG は「粒度過剰でデータ希薄」。自動入札時代は集約構造が妥当。一方、評価軸異質 (ブランド vs 一般) は分離が正しい。

### 米満氏理論の根拠引用 (`redesign_note`)
- G40: 「SKAG は粒度過剰でデータ希薄。集約推奨が妥当」
- G39: 「20KW 超は過密。集約 or 細分化判断」
- G30: 「細分化由来の自社競合」
- G31: 「評価軸が異なるので分離が正しい」(ブランド vs 一般)
- G17: 「1 コンテンツ 1AG 原則の上位概念」
- G70: 「Search/PMAX 重複防止」

### google_structure_dependency: **medium**
SKAG/STAG、PMAX、Search vs PMAX 重複は Google 固有の構造概念。ただし「集約 vs 分離の二軸思想」は媒体非依存。

### meta_applicability: **high**
Meta の Advantage+ Shopping / Audience の集約思想、CBO/ABO の構造設計に直接転用可能。

### tiktok_applicability: **high**
TikTok Smart+ の集約思想、Campaign Budget Optimization に転用可能。

### 関連原則
- **派生**: P2 (集約による学習データ十分化は学習保護と整合)
- **派生**: P8 (集約推奨は自動化前提時代の構造設計)

## P7. 目立ち度・バリエーション幅最大化原則 (Ad Rank pCTR 向上)

### 説明 (約 320 字)
広告の Ad Rank/視認性向上のため、「目立ち度 (拡張・表示オプション)」と「バリエーション幅 (短い見出し × 多パターン)」を最大化する。広告表示オプション、サイトリンク、コールアウト、構造化スニペット、画像拡張、プロモーション拡張、ビューアビリティ、動画完了率、冒頭 5 秒のフック、PMAX/RDA のアセット数、カルーセル多様性まで、すべて「目立ち度 = pCTR 向上 = Ad Rank 向上」の単一系譜で評価される。RSA は「短い見出し × 多バリエーション」を評価し、ピン留めはこの最大化を阻害する。これは P2 (機械学習保護) と整合し、システムが選ぶための材料を多く与えるという思想。

### 紐づくルール ID
G22, G22b, G22c, G22d, G34, G36, G37, G37b, G37c, G47, G48, G50, G52, G56, G58, G59, G63, G65, G65b, G66b, G67, G68b, G74, G77

### 業界常識との差分
- **業界常識**: クリエイティブは「ベストパフォーマー 1 本に絞る」。表示オプションは「とりあえず付ける」程度。
- **米満氏理論**: バリエーション幅を最大化し、システムに選ばせる。表示オプションは Ad Rank 向上の中核施策として網羅。

### 米満氏理論の根拠引用 (`redesign_note`)
- G22: 「目立ち度向上 = pCTR 向上 = Ad Rank 向上」
- G34: 「短い見出し x 多バリエーションを評価」
- G37: 「バリエーション最大化の前提」
- G65: 「バリエーション幅」
- G59: 「視聴維持 = pCTR/pVTR 向上」

### google_structure_dependency: **medium**
RSA、広告表示オプション、Ad Rank、PMAX アセットは Google 固有。ただし「バリエーション幅最大化」「目立ち度=システム選択材料」の思想は媒体非依存。

### meta_applicability: **high**
Meta Advantage+ Creative、Dynamic Creative、複数アセット入稿に直接転用可能。

### tiktok_applicability: **high**
TikTok Smart Creative、Automated Creative Optimization、複数素材入稿に直接転用可能。

## P8. 自動化前提の判断原則 (旧式手動運用の知識を捨てる)
