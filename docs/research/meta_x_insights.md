## 3. 横断分析

### テーマ別合意主張（最低2名以上確認）
- テーマ1 (ASC+): Andromeda 時代に「1キャンペーン集約」より「CR 多様性＋分割検証」が有効（@shev_webmarke / @naga_shingo / @social_savannah 合意）
- テーマ2 (クリエイティブ疲労): CTR 低下・Frequency 上昇を現場基準に回転、週次〜隔週刷新が実務感（@social_savannah / @theericcarlson）
- テーマ3 (学習フェーズ): 自動化基盤＋ AI 解析で突破。50CV 閾値より「属性データ質」が鍵（@theericcarlson / @naga_shingo / @ishigurodo）
- テーマ4 (iOS14以降計測): 管理画面 CV を過信せず、LP 一致・外部信号を重視（@theericcarlson / @naga_shingo）
- テーマ5 (公式との乖離): Broad 推奨に同意しつつ「属性× AI 細分化」で補完。キャンペーン統合より「勝者スタック＋自動化」
- テーマ6 (クリエイティブ量産): 月数百本レベル生産、フォーマット多様性、コンセプト→バリエーション検証（@social_savannah / @theericcarlson / @naga_shingo 強合意）

### Meta 公式と乖離する論点
1. 公式「1キャンペーン1 ad set・150 クリエイティブ集約」 vs 現場「CR 種別/属性分割＋人間監視」
2. 公式「編集控えめ」 vs 現場「AI 解析で積極介入」
3. 公式「Broad 一択」 vs 現場「Broad 基盤＋属性データで精密化」

### 業界常識を疑うインサイト 8件（複数合意ベース）
1. ASC+ は便利だが「Andromeda 後の戦国時代」では CR 多様性が命。集約だけでは埋もれる（@shev_webmarke + @naga_shingo）
2. クリエイティブ疲労は Meta 旗より「CTR/Frequency 実数」で判定。週次回転が標準（@social_savannah + @theericcarlson）
3. 学習フェーズは「50CV 待つ」ではなく AI 自動化＋属性データで短縮（@theericcarlson + @ishigurodo）
4. 管理画面 CV は「半分信じる」レベル。LP 完全一致で真の CVR がわかる（@theericcarlson + @naga_shingo）
5. Broad Audience は正しいが「属性合算データなし」では季節性・層を見誤る（@naga_shingo + @theericcarlson）
6. Advantage+ Creative より「勝者スタック＋人間解釈」がスケール実務（@theericcarlson + @social_savannah）
7. クリエイティブ量産は「月数百本」必須。AI で制作→人間で設計力が勝負（全運用者合意）
8. 公式推奨構造は「フロア（最低限）」。エッジは自動化インフラとデータ質（@theericcarlson + @ishigurodo + @naga_shingo）

## 4. 全体所見
現場運用者は Meta 公式の「集約・Broad・クリエイティブ重視」を基盤にしつつ、Andromeda/Andromeda 後時代の変化に対応した「AI+ 人間ハイブリッド」「属性データ精度」「勝者スタック」を強く実践。公式と乖離するポイントは「人間の解釈介入」と「細かい検証分割」。これらが「業界常識を疑う実戦知見」の核心。月予算規模が大きいほど自動化依存が高まる傾向あり。
